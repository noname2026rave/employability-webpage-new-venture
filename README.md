## Put it online with GitHub Pages (free)

1. Go to https://github.com and sign in (create a free account if needed).
2. Click the **+** (top right) → **New repository**.
3. Name it, for example, `employability-webpage`. Set it to **Public**. Click **Create repository**.
4. On the new repo page click **uploading an existing file**.
5. Drag in **index.html**, the **css** folder and the **images** folder (keep the folder structure). Click **Commit changes**.
6. Go to **Settings** → **Pages** (left menu).
7. Under **Build and deployment → Source** choose **Deploy from a branch**.
8. Set branch to **main** and folder to **/ (root)**. Click **Save**.
9. Wait about one minute. Your live link appears at the top of the Pages screen:
   `https://YOUR-USERNAME.github.io/employability-webpage/`

Share that link in your submission.

## Replacing the pictures with your own photos

The 5 images are original illustrations so nothing breaks online and there is no copyright issue.
To swap in your own evidence photos:

1. Put your photo in the `images` folder (for example `teamwork.jpg`).
2. In `index.html`, find the matching line, e.g. `src="images/teamwork.svg"`, and change it to `src="images/teamwork.jpg"`.
3. Commit the change on GitHub.

Keep the same width/height feel (landscape works best) so the layout stays tidy.
